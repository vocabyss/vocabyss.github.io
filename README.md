# vocabyss.github.io

Public site for the Vocabyss app: landing page, privacy policy (EN, RU) and terms of use.
Served by GitHub Pages at <https://vocabyss.github.io/>.

- `privacy/` — privacy policy (English is the canonical version), `privacy/ru/` — Russian.
- `terms/` — terms of use.
- `app-ads.txt` — AdMob authorised sellers file (publisher `pub-5451228985739251`); AdMob reads it from the developer website listed in Google Play.

Keep the privacy policy in step with the app's in-app privacy text (`lib/l10n/app_*.arb`, `privacyBody`).
